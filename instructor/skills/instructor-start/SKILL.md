# 교관 워크벤치 시작

사용자의 교육 업무에 맞는 **로컬 작업 환경**을 만든다. 질문을 한꺼번에 나열하지 말고 **한 번에 하나씩**, 답을 반영하며 묻는다. 이미 로컬 프로필에 있는 답은 짧게 확인하고 재질문하지 않는다. 이 패키지는 개인 제작 교육 도구이며 기관의 공식 시스템이나 보안 승인을 대신하지 않는다.

## 시작할 때

1. 현재 작업 공간의 `AGENTS.md`, `.harness/AGENTS.generated.md`, `.harness/profile.json`을 읽는다. 경로는 설치기가 출력한 경로를 사용하고 사용자의 홈·계정·기관명을 추측하지 않는다.
2. 저장된 설정이 있으면 역할·과목·대상·시간을 한 문장으로 보여 주고, 바꿀 항목부터 묻는다.
   첫 설치의 기본값은 사용자가 확인한 답변이 아니다. “처음 설정” 요청이면 기본값을 선택지로 제시하면서 실제 선호를 확인한다.
3. 새 설정이면 아래 질문을 순서대로 진행한다. 사용자가 "기본값으로"라고 하면 해당 기본값을 쓰되 최종 확인에서 알린다.

## 질문 순서

| 순서 | 설정 키 | 짧은 질문과 선택 예시 | 기본값 |
|---|---|---|---|
| 1 | `role` | 주로 어떤 교수 업무를 하나요? 교관 / 과정 설계 / 평가·피드백 | 교관 |
| 2 | `courses` | 공개 가능한 범위에서 과목이나 교육 주제를 알려 주세요. 예: 교수법, 의사소통, 안전교육의 일반 원리 | 일반 교수법 |
| 3 | `audience` | 학습자는 누구인가요? 입문자 / 경험자 / 혼합 | 성인 학습자 |
| 4 | `session_minutes` | 한 차시는 몇 분인가요? 50 / 80 / 직접 입력(10~480분) | 50 |
| 5 | `tasks` | 먼저 만들 자료를 골라 주세요. 강의안 / 실습자료 / 평가문항 / 피드백 | 강의안, 실습자료, 평가문항 |
| 6 | `tone` | 자료의 문체는 어떤가요? 간결한 업무 문장 / 친절한 학습 안내 / 토론 중심 | 명확하고 간결한 한국어 |
| 7 | `agent` | 지금 사용할 도구는 무엇인가요? Codex / Claude / 둘 다 / 수동으로 자료 복사 | manual |
| 8 | `workspace` | 설치기가 정한 자료 폴더를 사용할까요? 유지 / 새 작업실로 별도 설치 | 현재 설치기의 작업 공간 |

사용자가 말한 내용 중 개인 식별정보, 내부 운영·시설·장비 세부, 비공개 교육 자료를 프로필에 저장하지 않는다. 그런 자료가 나오면 공개 가능한 교수 목표나 가상 사례로 바꾸어 질문을 이어 간다. 비밀번호·API 키는 질문하지 않으며 프로필에 저장하지 않는다.

## 답을 설정으로 반영하기

1. 답을 위 키의 JSON으로 정리한다. `tasks`는 문자열 배열, `session_minutes`는 정수, `agent`는 `codex`, `claude`, `both`, `manual` 중 하나다. `workspace`에는 사용자가 확인한 실제 로컬 경로만 쓴다.
   기존 작업실 위치는 `configure`로 이동할 수 없다. 위치 변경을 원하면 새 `--root`와 `--workspace`로 별도 설치한 뒤 설정을 가져오도록 안내한다.
2. 설정 요약과 저장 위치를 보여 주고 확인받는다. 확인 전에는 설정을 덮어쓰지 않는다.
3. 터미널을 사용할 수 있으면 설치기가 알려 준 `harness.py`의 도움말을 확인하고, JSON을 임시 파일에 저장하여 다음 명령으로 반영한다. 실제 설치 경로와 작업 공간을 사용하고 기존 파일은 설치기의 충돌 검사에 맡긴다.

   ```text
   python "<설치 경로>/bundle/harness.py" configure --root "<설치 경로>" --answers "<설정 JSON 파일>"
   ```

4. 명령이 성공했는지 확인하고 `doctor`로 로컬 환경을 점검한다. 오류를 숨기거나 기존 전역 AI 설정을 임의로 수정하지 않는다.
5. 터미널이 없으면 JSON을 사용자에게 전달하고 실행 명령을 안내한다. 저장하지 않았다면 저장했다고 말하지 않는다.

## 첫 작업으로 연결하기

설정이 끝나면 `lesson-design`, `assessment`, `materials` 중 우선 작업 하나를 골라 시작한다. 예: "50분 수업의 목표 2개와 짧은 실습부터 만들겠습니다." 첫 산출물은 비공개 자료 없이도 실행할 수 있는 공개·가상 사례로 만든다.

공통 스킬·템플릿 동기화는 설치기가 제공하는 `sync` 명령만 사용한다. 개인 프로필과 작성 자료를 GitHub로 올리지 않는다. 다른 AI 호출·Reason Network 가입·메시지 전송·클라우드 계정 연결은 설치 완료와 별개의 사용자 요청이 있을 때 진행한다.
