# 평가와 피드백

평가할 학습 목표와 수업 활동을 먼저 읽는다. 목표가 없으면 "무엇을 할 수 있는지 확인할까요?"부터 한 가지씩 묻는다. 분류·설명 목표를 암기 문항만으로, 시연 목표를 지필 문항만으로 확인했다고 주장하지 않는다.

## 문항 만들기

1. 목표별 문항 수·형식·인지 수준을 작은 출제표로 제시한다. 형식은 선택형, 짧은 서술, 수행 관찰 중 목표에 맞게 고른다.
2. 질문에는 한 가지 핵심 판단을 담는다. 이중 부정·과도한 독해 부담·불필요한 배경지식을 줄인다.
3. 선택형은 정답 근거와 각 오답의 오개념을 설명한다. 정답이 둘 이상 가능하면 고치고, "항상·절대" 등 단서로 답을 추측하게 하지 않는다.
4. 서술·수행 평가는 `templates/assessment-rubric.md`를 사용한다. 평가 요소, 수준별 관찰 기준, 배점, 예시 피드백을 적는다. 수준 차이를 "우수·보통·미흡"이라는 말만으로 대신하지 않는다.
5. 배점 합계를 검산하고, 같은 결과물이 여러 평가 요소에서 중복 감점되지 않는지 확인한다.

## 문항 검토

문항별로 목표 대응, 정답 근거, 다른 정답 가능성, 용어의 명확성, 예상 시간을 확인한다. 근거 자료가 없으면 "검증 필요"라고 표시한다. 직접 시험하지 않은 문항의 난이도·신뢰도·타당도를 수치로 만들어 내지 않는다. 실제 통계 분석이 필요하면 비식별 자료와 적절한 분석 도구가 있어야 한다.

## 피드백 작성

사람을 평가하는 표현보다 결과물의 관찰 사실을 쓴다. "확인된 강점 → 개선할 행동 한 가지 → 다시 해볼 과제" 순서로 짧게 제시한다. 실제 이름·성적·인사 자료를 외부 AI나 동기화 저장소에 넣지 않는다. 연수 시연은 가상 학습자와 가상 답안을 사용한다.

완료할 때 문항·정답·해설·평가표를 서로 대조한다. 새 파일로 저장하고, 교관의 검토가 필요한 사실·교육 기준과 가상 예시를 표시한다.
